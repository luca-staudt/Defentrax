# Screenshot placeholders

UI screenshots for the root README and marketing docs will be added during
**Phase 21 (v1.0 release prep)**.

Until then, this directory intentionally holds **placeholders only** — no stock
or mock “product” images that could misrepresent the current UI.

| Planned file | Subject |
|--------------|---------|
| `login.png` | Login / TOTP |
| `dashboard.png` | Dashboard stats + open alerts |
| `alert-detail.png` | Alert lifecycle + timeline |
| `rules.png` | Rule list / enable toggles |

Capture guidance (when taking real shots):

- Use a local Compose stack with sample/dev data only — never production PII.
- Prefer dark UI at ~1280×720 or 1600×900.
- Redact hostnames/IPs if sharing publicly beyond this repo’s needs.
